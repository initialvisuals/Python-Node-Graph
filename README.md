# Python Node Graph

A Python **node editor** experiment — visual graphs for programming flows, mesh-network style distance / signal ideas, and GPT-flavored nodes.

Part of the [Initial Visuals](https://github.com/initialvisuals) toolkit / game lab.

![Node graph UI](https://github.com/initialvisuals/Python-Node-Graph/assets/13159899/83ea8a56-397e-452e-9450-9eb00308e309)

### Status

**Learning asset / WIP.** Unique IDs and connection counts work. Variable passing between node types, GPT node behavior, flow direction, and output preview still need love. There are known bugs. Steal the bones; don’t expect a finished product.

Useful as a sketch for:

- Mesh / signal-strength graphs (distance through walls, attenuation)
- Self-healing connections that drop and reattach under rules
- A stripped node runtime you can grow into a real tool

### Quick start

```bash
python main.py
```
